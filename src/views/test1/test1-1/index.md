# 快速开始

新增一篇文档只需一步：建目录，放 `index.md`。

## 目录即菜单

```
src/views/
└── 前端/
    ├── index.md          -> /前端
    └── vue3/
        └── index.md      -> /前端/vue3
```

侧边栏菜单名直接取目录名，不需要任何配置文件。

## 控制菜单顺序

同级目录按名称排序，支持数字前缀：

```
src/views/前端/
├── 01-入门/
├── 02-进阶/
└── 03-源码/
```

排序用的是 `localeCompare` 的 `numeric` 选项，所以 `2-xxx` 会排在 `10-xxx` 前面。

## 只做分组的目录

目录里不放 `index.md` 时，它只作为可折叠的分组出现在菜单里，点击不跳转。
